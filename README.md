# Vocab Daily

Android home-screen widget: one vocabulary word per day (offline).

## Themes

Students can pick in the app (updates the widget too):

1. **Grove** — forest card, DM Sans  
2. **Ink** — paper study, Literata serif  
3. **Coast** — bright air, Literata + DM Sans
